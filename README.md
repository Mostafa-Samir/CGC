# Computational Graph Completion


## For Development
_Usage of `uv` is recommended_
1. Make sure to use a python version >= 3.11
2. Clone the repo
3. In your venv, run `pip install -e ".[dev]"`. If you have a GPU, you can utilize it by running `pip install -e ".[dev, cuda12]"` (for CUDA v12) or `pip install -e ".[dev, cuda13]"` (for CUDA v13)
